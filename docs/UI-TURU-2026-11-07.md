## 4. Ertelenenler ve gerekçeleri

1. **DESIGN.md §4 "gölgesiz/kart gölgesiz" ile global.css "basılabilir dudak" çelişkisi.**
   `tokens.css` `--bas-derinlik`, `--golge`, `--golge-buyuk` jetonlarını tanımlıyor;
   `.dugme`, `.secenek`, mozaik/arşiv kartları bu jetonları kullanıyor. Bu bir tasarım
   evrimi kararı (tüm uygulamada görsel değişiklik) — tek başına geri almak kapsamlı
   regresyon riski taşır. **Karar sahibi:** Lead / tasarım.
2. **`rotaHaritasi.ts` MapLibre işareti `div` + `click`.** İşaretler `aria-hidden` ve odak
   almaz; erişilebilir yol sayfadaki numaralı listede 44px düğmelerle mevcut. `<button>`e
   çevirmek harita içine onlarca sekme durağı ekler ve işareti klavye listesiyle
   eşleştirme yükü doğurur. Dokunma hedefi yine de 44px'e çıkarıldı (#4).
3. **Ham px boşluk / font-size temizliği (#16–#18).** Ölçek dışı değerlerin çoğu optik
   hiza (mühür, pul, rozet) veya sabit boyutlu süs/işaret; birebir jeton dönüşümü pikselleri
   değiştirmeden dev diff üretir. İşlevsel tipografi zaten jetonlarda.
4. **`rotaHaritasi.ts` / `bolgeHaritasi.ts` içindeki MapLibre paint yedek hex'leri.**
   Canvas katmanı CSS `var()` okuyamaz; jeton değerlerinin TS sabitleri olarak yedeklenmesi
   zorunlu. Jeton değişirse bu sabitler elle güncellenmeli (yorumlarda belirtildi). Test
   kapsamı CSS ile sınırlı.
5. **Sertifika SVG'sindeki px tipografi ve büyük harf belge başlığı.** Çıktı belgesi
   (viewBox user unit + yazdırma); arayüz ölçeğine bağlanmamalı.

## 5. Yeni regresyon testi — `tests/ui-tutarlilik.test.ts`

9 test, ~40 ms:

1. `tokens.css` dışında ham hex/rgb/hsl yok (yorumlar ayıklanır).
2. `div/span/li` açılış etiketlerinde `onClick` yok; tek istisna gerekçeli beyaz listede.
3. Jeton bütünlüğü: `var(--x)` tokens.css'te ya da aynı dosyada tanımlı olmalı; JS'in
   yazdığı 7 dinamik prop beyaz listede (yorumlarıyla).
4. 320px taşma: `minmax(300px, …)` gibi sabit minimumlar `min(100%, …)` ile korunmalı
   (288px içerik alanı kuralı).
5. `text-transform: uppercase` yasağı.
6. `.dugme`, `.dugme--kucuk`, `.secenek` dokunma hedefi ≥ 44px + global `:focus-visible`
   halkasının varlığı.
